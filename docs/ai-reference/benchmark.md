# Benchmarks

A benchmark is another instrument's price series, compared against the portfolio's time-weighted
return over the same window. Money-weighted return is never compared to an index: the index has no
contributions to be timed.

Two windows are involved and they need not be the same. If the benchmark's price history starts
later than the period asked for — a recently listed ETF against a ten-year portfolio — both sides
are narrowed to the overlap, and the comparison reports the window it actually compared. A
benchmark younger than the period is not missing data; reporting the portfolio's ten-year return
against the ETF's two-year return would be.

**Excess return** is the portfolio's return minus the benchmark's over that shared window. It is a
difference of two percentages, in percentage points.

A benchmark quoted in another currency carries that currency's movement into the comparison, in the
same way the portfolio's own foreign holdings do. When the gap is puzzling, the exchange rate is
worth checking before the instrument selection is blamed.
