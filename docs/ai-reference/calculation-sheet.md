# The calculation sheet

A period's result written out row by row: what the portfolio opened with, what was paid in or
taken out, what the market did, what it earned and paid, and what it closed at. It introduces no
new figure — every column is one already reported, narrowed to one chunk of the period. The sheet
exists so the headline return can be followed rather than believed.

## The identity every row keeps

**Closing = opening + flows + result.** The opening value of a row is the closing value of the row
above it, so the rows chain: add every flow and every result and you land on the closing value of
the last one. The first row opens on what was there *before* the period began, which at inception
is zero rather than the first purchase — the first day's own deposit is money paid in, not an
opening balance.

**Result = market + income − costs.** The three parts answer "where did the money come from":

- *Market* is the change in what the holdings are worth.
- *Income* is dividends and interest credited, stated **gross**, before any tax withheld.
- *Costs* are the fees and taxes actually paid, trade commissions included and the tax withheld
  from a dividend included. This is the cost figure a fee rate divides by, not the narrower list
  of standalone fee and tax entries the charges report shows.

A month where a dividend arrived and nothing else moved therefore shows income, costs and a result
— with the market column at zero. That is not a missing number.

## The return column

Each row carries its own time-weighted return, and the next column carries the rows so far chained
together. **The last chained value is the period's own return**, the same figure shown above the
sheet. Returns chain by multiplication, never by addition: three months of +10% are +33.1%, not
+30%.

Money paid in or out is deliberately not a return. A month where the value doubled because of a
deposit shows the deposit in the flows column and a return near zero.

## Traps worth naming

- **A rising value is not a result.** The flows column is what separates the two, and it is the
  first place to look when a value and a return disagree.
- **Splitting finer does not change the total.** Reading the same period by day, month or year
  gives the same closing value and the same period return; only the rows differ.
- **Costs here are wider than on the reports screen.** A purchase commission is part of what the
  instrument cost and is counted here; the charges report lists standalone fees and taxes only.
- The sheet follows both the account lens and the date the app is set to, exactly like every other
  figure over a period.
